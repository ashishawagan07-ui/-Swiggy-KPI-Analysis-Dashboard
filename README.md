# 📊 Swiggy Sales Analytics Dashboard

## 🚀 Project Overview
The Swiggy Sales Analytics Dashboard is an interactive Excel-based business intelligence project designed to analyze sales performance, customer ratings, order trends, food category preferences, restaurant performance, and regional sales distribution.

The dashboard transforms raw Swiggy data into meaningful insights through dynamic visualizations, KPI cards, charts, maps, and slicers, enabling data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Monitor customer ratings and order volume
- Identify top-performing cities and states
- Track monthly, weekly, and daily sales trends
- Compare food category sales contribution
- Explore restaurant-level performance
- Generate actionable business insights

---
